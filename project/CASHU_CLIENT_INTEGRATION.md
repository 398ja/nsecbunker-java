# nsecBunker Integration with cashu-client Identity Plugin

## Overview

This document explains how to integrate nsecBunker with the cashu-client identity plugin to enable:
- Centralized, secure storage of Nostr private keys (nsecs) in nsecBunker
- Remote signing of Nostr events from the cashu-client via NIP-46
- Programmatic permission management with granular access control
- Specific event kind restrictions (e.g., only allow signing of certain event types)

## Integration Approach

### 1. Key Storage in nsecBunker

Instead of storing private keys locally in the cashu-client's identity plugin, keys are:
- Generated by cashu-client (or imported)
- Transmitted securely to nsecBunker once
- Encrypted and stored in nsecBunker's config file
- Never stored in plaintext on the cashu-client side

### 2. Remote Signing via NIP-46

When cashu-client needs to sign an event:
1. Creates an unsigned Nostr event
2. Sends NIP-46 `sign_event` request to nsecBunker via Nostr relays
3. nsecBunker checks permissions against policies
4. If authorized, signs the event and returns the signature
5. cashu-client attaches the signature to the event

### 3. Permission Management

Permissions are managed through:
- **Policies**: Define what operations are allowed (methods, event kinds, usage limits)
- **Tokens**: Time-limited access credentials
- **KeyUsers**: Associate specific pubkeys with keys
- **SigningConditions**: Granular rules per KeyUser

## Implementation Guide

### Phase 1: Setup nsecBunker

#### 1.1 Add Keys to nsecBunker Programmatically

```typescript
// add-cashu-identity.ts
import { saveEncrypted } from './src/commands/add.js';
import { PrismaClient } from '@prisma/client';
import { nip19, getPublicKey } from 'nostr-tools';

const prisma = new PrismaClient();

async function addCashuIdentityKey(
    identityId: string,
    nsec: string,
    passphrase: string
) {
    const configPath = 'config/nsecbunker.json';
    const keyName = `cashu-${identityId}`;

    // 1. Encrypt and save to config
    await saveEncrypted(configPath, nsec, passphrase, keyName);
    console.log(`✓ Key ${keyName} encrypted and saved`);

    // 2. Register in database
    const decoded = nip19.decode(nsec);
    const privkey = decoded.data as string;
    const pubkey = getPublicKey(privkey);

    await prisma.key.upsert({
        where: { keyName },
        update: { pubkey },
        create: { keyName, pubkey }
    });

    console.log(`✓ Key ${keyName} registered in database`);
    return { keyName, pubkey };
}

// Usage
const identity = await addCashuIdentityKey(
    'user-alice-wallet',
    'nsec1...',
    'secure-passphrase'
);
```

```typescript
    // 1: Short text note

    // 7: Reaction

    // 9735: Zap receipt
```

#### 1.3 Grant Permissions to cashu-client

```typescript
// grant-cashu-permissions.ts
import { PrismaClient } from '@prisma/client';
import { allowAllRequestsFromKey } from './src/daemon/lib/acl/index.js';

const prisma = new PrismaClient();

async function grantCashuClientPermissions(
    keyName: string,
    cashuClientPubkey: string,
    policyId: number
) {
    // 1. Create/Update KeyUser
    const keyUser = await prisma.keyUser.upsert({
        where: {
            unique_key_user: {
                keyName,
                userPubkey: cashuClientPubkey
            }
        },
        update: {},
        create: {
            keyName,
            userPubkey: cashuClientPubkey,
            description: 'cashu-client instance'
        }
    });

    console.log(`✓ KeyUser created/updated: ${keyUser.id}`);

    // 2. Apply policy rules as signing conditions
    const policy = await prisma.policy.findUnique({
        where: { id: policyId },
        include: { rules: true }
    });

    if (!policy) {
        throw new Error(`Policy ${policyId} not found`);
    }

    for (const rule of policy.rules) {
        await prisma.signingCondition.create({
            data: {
                keyUserId: keyUser.id,
                method: rule.method,
                kind: rule.kind,
                allowed: true,
            }
        });
        console.log(`✓ Granted: ${rule.method} ${rule.kind ? `kind=${rule.kind}` : ''}`);
    }

    return keyUser;
}

// Usage
await grantCashuClientPermissions(
    'cashu-user-alice-wallet',
    'hex-pubkey-of-cashu-client-instance',
    1 // Policy ID
);
```

For time-limited access or token-based authentication:

```typescript
// create-cashu-token.ts
import { PrismaClient } from '@prisma/client';
import crypto from 'crypto';

const prisma = new PrismaClient();

async function createCashuAccessToken(
    keyName: string,
    policyId: number,
    clientName: string = 'cashu-client',
    durationInHours?: number
) {
    // Generate random token
    const token = crypto.randomBytes(32).toString('hex');

    const data: any = {
        keyName,
        clientName,
        policyId,
        createdBy: 'system', // or admin pubkey
        token
    };

    if (durationInHours) {
        data.expiresAt = new Date(
            Date.now() + (durationInHours * 60 * 60 * 1000)
        );
    }

    const tokenRecord = await prisma.token.create({ data });

    // Get the key's npub
    const key = await prisma.key.findUnique({
        where: { keyName }
    });

    if (!key) {
        throw new Error(`Key ${keyName} not found`);
    }

    const npub = nip19.npubEncode(key.pubkey);
    const bunkerToken = `${npub}#${token}`;

    console.log(`✓ Created token: ${bunkerToken}`);
    console.log(`  Expires: ${data.expiresAt || 'Never'}`);

    return bunkerToken;
}

// Usage
const token = await createCashuAccessToken(
    'cashu-user-alice-wallet',
    1, // Policy ID
    'cashu-client-alice',
    24 * 7 // 7 days
);
```

### Phase 2: Modify cashu-client Identity Plugin

#### 2.1 Create NIP-46 Signer Adapter

```java
// RemoteNsecBunkerSigner.java
package xyz.tcheeric.identity.infrastructure.signing;

import nostr.base.PrivateKey;
import nostr.base.PublicKey;
import nostr.base.Signature;
import nostr.event.BaseEvent;
import xyz.tcheeric.identity.api.exceptions.SigningException;

import java.util.concurrent.CompletableFuture;
import java.util.concurrent.TimeUnit;

/**
 * NIP-46 remote signer that connects to nsecBunker.
 *
 * Instead of holding the private key locally, this signer
 * sends signing requests to a remote nsecBunker instance
 * via Nostr relays.
 */
public class RemoteNsecBunkerSigner {

    private final String bunkerConnectionString;
    private final PublicKey localPubkey;
    private final PrivateKey localPrivkey; // Ephemeral, for NIP-46 comms
    private final Nip46Client nip46Client;

    public RemoteNsecBunkerSigner(
        String bunkerConnectionString,
        String[] relays
    ) {
        this.bunkerConnectionString = bunkerConnectionString;

        // Generate ephemeral keypair for NIP-46 communication
        // This is NOT the identity key - just for secure comms
        KeyPair ephemeral = KeyGenerator.generateKeyPair();
        this.localPubkey = ephemeral.publicKey();
        this.localPrivkey = ephemeral.privateKey();

        // Parse bunker connection string
        // Format: bunker://npub@relay1,relay2
        BunkerConnection conn = BunkerConnection.parse(bunkerConnectionString);

        this.nip46Client = new Nip46Client(
            localPrivkey,
            conn.getBunkerPubkey(),
            relays
        );
    }

    /**
     * Signs an event remotely via nsecBunker.
     */
    public Signature signEvent(BaseEvent event) throws SigningException {
        try {
            // Send NIP-46 sign_event request
            CompletableFuture<Signature> future = nip46Client.signEvent(event);

            // Wait for response (with timeout)
            return future.get(30, TimeUnit.SECONDS);

        } catch (Exception e) {
            throw new SigningException(
                "Failed to sign event via nsecBunker: " + e.getMessage(),
                e
            );
        }
    }

    /**
     * Connects to the bunker and requests permission.
     */
    public void connect() throws SigningException {
        try {
            CompletableFuture<Boolean> future = nip46Client.connect();
            Boolean connected = future.get(30, TimeUnit.SECONDS);

            if (!connected) {
                throw new SigningException("Failed to connect to nsecBunker");
            }

        } catch (Exception e) {
            throw new SigningException(
                "Failed to connect to nsecBunker: " + e.getMessage(),
                e
            );
        }
    }

    public void disconnect() {
        nip46Client.disconnect();
    }
}
```

#### 2.2 NIP-46 Client Implementation

```java
// Nip46Client.java
package xyz.tcheeric.identity.infrastructure.signing;

import nostr.base.*;
import nostr.event.BaseEvent;
import nostr.event.impl.GenericEvent;
import nostr.event.impl.Filters;
import nostr.event.json.codec.BaseEventEncoder;

import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ConcurrentHashMap;
import java.util.Map;
import java.util.UUID;

/**
 * NIP-46 (Nostr Connect) client implementation.
 *
 * Communicates with remote signers via encrypted Nostr events.
 */
public class Nip46Client {

    private final PrivateKey localPrivkey;
    private final PublicKey remotePubkey;
    private final String[] relays;
    private final Map<String, CompletableFuture<?>> pendingRequests;

    private NostrRelay relayConnection;

    public Nip46Client(
        PrivateKey localPrivkey,
        PublicKey remotePubkey,
        String[] relays
    ) {
        this.localPrivkey = localPrivkey;
        this.remotePubkey = remotePubkey;
        this.relays = relays;
        this.pendingRequests = new ConcurrentHashMap<>();
    }

    public CompletableFuture<Boolean> connect() {
        CompletableFuture<Boolean> future = new CompletableFuture<>();

        // Connect to Nostr relays
        this.relayConnection = new NostrRelay(relays);
        relayConnection.connect();

        // Subscribe to responses (kind 24133)
        Filters filters = new Filters();
        filters.setKinds(List.of(24133));
        filters.setAuthors(List.of(remotePubkey.toString()));
        filters.setSince(System.currentTimeMillis() / 1000);

        relayConnection.subscribe(filters, this::handleResponse);

        // Send connect request
        String requestId = UUID.randomUUID().toString();
        sendRequest(requestId, "connect", new String[]{});

        pendingRequests.put(requestId, future);
        return future;
    }

    public CompletableFuture<Signature> signEvent(BaseEvent event) {
        CompletableFuture<Signature> future = new CompletableFuture<>();

        String requestId = UUID.randomUUID().toString();

        // Serialize event to JSON
        String eventJson = new BaseEventEncoder().encode(event);

        sendRequest(requestId, "sign_event", new String[]{ eventJson });

        pendingRequests.put(requestId, future);
        return future;
    }

    private void sendRequest(String id, String method, String[] params) {
        // Create NIP-46 request
        String content = createNip46Request(id, method, params);

        // Encrypt with NIP-04
        String encrypted = Nip04.encrypt(localPrivkey, remotePubkey, content);

        // Create kind 24133 event
        GenericEvent request = new GenericEvent(
            localPrivkey.getPublicKey(),
            24133,
            encrypted
        );
        request.addTag("p", remotePubkey.toString());

        // Sign and publish
        request.sign(localPrivkey);
        relayConnection.publish(request);
    }

    private String createNip46Request(String id, String method, String[] params) {
        // Format: ["req", <id>, <method>, <params...>]
        return String.format(
            "[\"req\",\"%s\",\"%s\",%s]",
            id,
            method,
            paramsToJson(params)
        );
    }

    private void handleResponse(GenericEvent event) {
        // Decrypt NIP-04 content
        String decrypted = Nip04.decrypt(localPrivkey, remotePubkey, event.getContent());

        // Parse response: ["res", <id>, <result>]
        Nip46Response response = parseNip46Response(decrypted);

        // Resolve pending request
        CompletableFuture future = pendingRequests.remove(response.getId());
        if (future != null) {
            if (response.isError()) {
                future.completeExceptionally(
                    new Exception(response.getError())
                );
            } else {
                future.complete(response.getResult());
            }
        }
    }

    public void disconnect() {
        if (relayConnection != null) {
            relayConnection.disconnect();
        }
    }
}
```

#### 2.3 Integrate with Identity Plugin

```java
// RemoteIdentityStorage.java
package xyz.tcheeric.identity.infrastructure.remote;

import xyz.tcheeric.identity.api.ports.IdentityStorage;
import xyz.tcheeric.identity.domain.PrivateKey;
import xyz.tcheeric.identity.api.exceptions.IdentityStorageException;

/**
 * Storage adapter that delegates to remote nsecBunker.
 *
 * Private keys are never stored locally - all operations
 * are performed via NIP-46 remote signing.
 */
public class RemoteIdentityStorage implements IdentityStorage {

    private final Map<String, RemoteNsecBunkerSigner> signers;
    private final String[] relays;

    public RemoteIdentityStorage(String[] relays) {
        this.signers = new ConcurrentHashMap<>();
        this.relays = relays;
    }

    /**
     * "Saves" a private key by creating a NIP-46 connection.
     * The key itself is stored in nsecBunker, not locally.
     */
    @Override
    public void save(String identityId, PrivateKey privateKey)
            throws IdentityStorageException {
        throw new UnsupportedOperationException(
            "Cannot save keys locally. " +
            "Keys must be added to nsecBunker directly."
        );
    }

    /**
     * Registers a bunker connection for an identity.
     */
    public void registerBunkerConnection(
        String identityId,
        String bunkerConnectionString
    ) throws IdentityStorageException {
        try {
            RemoteNsecBunkerSigner signer = new RemoteNsecBunkerSigner(
                bunkerConnectionString,
                relays
            );

            signer.connect();
            signers.put(identityId, signer);

        } catch (Exception e) {
            throw new IdentityStorageException(
                "Failed to connect to nsecBunker: " + e.getMessage(),
                e
            );
        }
    }

    /**
     * Returns a signer proxy (not the actual private key).
     */
    @Override
    public PrivateKey load(String identityId)
            throws IdentityStorageException {
        RemoteNsecBunkerSigner signer = signers.get(identityId);
        if (signer == null) {
            throw new IdentityStorageException(
                "No bunker connection for identity: " + identityId
            );
        }

        // Return a proxy that delegates to remote signer
        return new RemotePrivateKeyProxy(identityId, signer);
    }

    @Override
    public boolean exists(String identityId) {
        return signers.containsKey(identityId);
    }

    @Override
    public void delete(String identityId) throws IdentityStorageException {
        RemoteNsecBunkerSigner signer = signers.remove(identityId);
        if (signer != null) {
            signer.disconnect();
        }
    }
}
```

## Security Considerations

### 1. Permission Scoping

Always use the principle of least privilege:
- Grant only necessary event kinds
- Use usage limits where appropriate
- Set expiration times on tokens
- Regularly audit and revoke unused permissions

### 2. NIP-46 Communication Security

- Uses NIP-04 encryption for all communication
- Ephemeral keypairs for client-side communication
- Timeout mechanisms to prevent hanging requests
- Relay authentication where available

### 3. Key Isolation

- Private keys never leave nsecBunker
- cashu-client never has access to raw private keys
- Each identity has independent permissions
- Revocation is instant and effective

### 4. Audit Trail

nsecBunker maintains logs of:
- All signing requests
- Permission grants/denials
- Key usage timestamps
- Failed authentication attempts

## Performance Considerations

### Latency

NIP-46 remote signing adds network latency:
- Typical signing time: 100-500ms
- Relay-dependent (use nearby relays)
- Consider caching signatures for repeated operations

### Optimization Strategies

1. **Batch Operations**: Queue multiple signing requests
2. **Local Caching**: Cache public keys and metadata
3. **Connection Pooling**: Maintain persistent relay connections
4. **Token-Based Auth**: Reduce per-request overhead
